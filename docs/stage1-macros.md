# 阶段一：寻址与算术宏证明

所有程序都由 `tools/macros.py` 生成。Python 只构造固定 PP3 源码；程序输入不会送入生成器。

下文的 X 是宏模板里的地址占位符，运行前必须替换为具体整数地址。

## 地址分配和数据不变量

生成器先静态运行一次宏构造过程，统计变量槽数量 N，再以 `B=N+1` 生成最终源码。槽地址是 `-1` 到 `-N`；变量中只存非负整数或不大于 `-B` 的负整数。地址 0 是临时指针，其余内存默认是 0。每个程序按这一规则从自己的宏布局重新求 B，未硬编码槽上限。

这样，任一非零变量数据 V 都满足 `memory[V]=0`：非负 V 不是变量槽；负载荷 V 不会落入 `-N..-1`；零单独分析。

## 安全写槽

选择并清空槽 X：

```text
&0 ^1 &X ^3 &0 ^2
```

先令 `memory[0]=0`。从 X 执行深度 3 的写入：若 `memory[X]=0`，路径为 `X→0→0`；若旧值为 V 非零，路径为 `X→V→0`。因此两种情况下都令 `memory[0]=X`。最后深度 2 从地址 0 跳到 X 并写零。

随后执行表达式并 `^3` 写回新值 W。表达式不能依赖 X 的旧值，也不能破坏临时指针。若 W 非零，路径 `W→0→X`；若 W 为零，路径 `0→X→0`，最终写零到地址 0。因为 X 在准备时已经清零，目标赋值仍然成立。下次访问重新设置临时指针即可。

## 自环读改写

下面是在数据不变量下自增/自减一的宏；操作后的新值也必须避开保留地址，例如不能把 0 直接减成保留地址 -1：

```text
&0 ^1 &X ^3 &X *1 @+ ^3
```

`&0 ^1` 先清地址 0；`&X ^3` 再令 `memory[0]=X`，此时 X 仍保存旧值。`&X *1` 把旧值 V 交换到 view，同时令 `memory[X]=X`，形成自环。执行自增/自减后 `^3`：若新值非零，沿 `W→0→X`；若为零，沿 `0→X→X`。因此旧值和新值为零都可处理。这个技巧将旧版“复制到临时槽、清槽、写回”简化为一次自环交换；其证明依赖其他保留槽和数据范围不变量。

复制槽使用安全 `put`；循环以当前 view 是否为零作条件。`if_nonzero` 将任意非零条件放入只执行一次的循环，正文末尾写零退出，再用 0/1 标志实现另一分支。所有条件值即使为负也只在 view 中作为循环条件，不写入数据槽。

## 有符号整数解码

`decode_integer` 在整数 `@input` 后先将输入与有限集合 `0,-1,...,-B` 比较。命中时直接产生非负幅值和符号标志，避免把可能撞槽地址的值保存为普通变量。

其余输入满足 `x>0` 或 `x<-B`。初始化 `p=q=x,k=0`，每轮令 `p-=1,q+=1,k+=1`。

- 若 `x>0`，p 先到 0，得到幅值 k=x、正号；q 为正。
- 若 `x<-B`，q 先到 `-B`，此时 `k=-B-x`，得到幅值 `k+B=-x`、负号；p 和 q 始终不大于 `-B`。

每轮只检查零，因此适配 DSL 的分支能力。分类后的普通变量只存安全范围内的幅值和 0/1 符号。

## 十进制字符编解码

P003 在首字符位置识别可选的 ASCII `+` 或 `-`，之后只接受 `0..9`；LF 结束该行。任何其他字符设置错误标志，但继续排空到 LF。幅值按从左至右的循环更新：

```text
m = 10*m + digit
```

乘十通过复制旧值、清零后重复十次自增完成，再用非负加法宏累加 digit。最终值为零时不输出负号。

输出不依赖 Python 的字符串转换：先通过非负长除法逐次除以 10 找最高十进制位权，再逐位计算商和余数。商加 ASCII `0` 的码点 48 后用 `@print_as_char` 输出，余数成为下一位的待处理值。完成后输出 LF。非法输入固定输出 `ERROR\n`。

## 有符号乘法

P004 先把输入解码为 `(幅值,负号)`。计数器初始为第二个幅值，乘积初始为零。每轮将第一个幅值加进乘积，计数器减一。完成 k 轮后 `product=k*|A|`、`counter=|B|-k`；结束时乘积为 `|A||B|`。结果为零不打印负号，否则仅当输入符号不同才打印负号。

复杂度按更新次数为 `O(|A||B|)`，并非大数乘法算法。计数器和乘积占内存槽；用标准自增逐次累加，所以大输入会非常慢。

## 非负长除法和 GCD

除法宏约定 `A>=0,B>0`，用工作变量复制 A，用倒计数复制 B。每步让工作量减一、余数加一、倒计数减一。倒计数到零意味着又减去了一个完整 B：余数清零、商加一、倒计数恢复 B。

当工作量归零，循环不变量为：

```text
A = B*Q + R
0 <= R < B
```

因此 Q 和 R 分别为非负商、余数。禁止以 B=0 调用该宏；GCD 的外层循环仅在 b 非零时进入，`gcd(0,0)=0` 则自然直接返回。

GCD 迭代 `(a,b)←(b,a mod b)`。由 `a=qb+r` 得 `gcd(a,b)=gcd(b,r)`；且 `0<=r<b`，第二分量严格变小，最终为零并返回第一分量。输入符号由解码后丢弃，故结果非负。
