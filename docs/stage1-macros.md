# 阶段一：通用比较、整数输入和算术宏

`tools/macros.py` 只在编译期生成文本，输入始终交给原版 PP3。此次采用 [PP3-Lab 的图模型与局部路由记录](https://github.com/JDK8u341/PP3-Lab/tree/3debbe3b5b580c2e4a86ab0f0c1d3ba050adfda6)，撤掉按数字值和整段保留地址展开的分类。

## 数据布局

两个永久零锚点位于 -1、-2，普通槽从 -3 向负侧分配。若共有 N 个静态槽，动态数据区起点为 `-B=-(N+3)`。两遍生成保证全部临时槽在运行前已确定，不能运行途中继续分配静态槽。

普通槽只存自然数。正地址只允许 0 或指向零锚点的标记，因此自然数到零最多两步。引用、数组指针和裸整数工作槽分别有专用宏，不用普通自然数赋值。数组和记录堆不能共用同一动态区。

## 自环补齐路径

令 `f(a)=memory[a]`，深度 d 的写入目标是 `f^(d-1)(view)`。向普通槽 P 赋值：

```text
&0 ^1 &P ^4 &P ^1 EXPRESSION ^4
```

清零 0 后，P 经旧自然数、可选标记到 0 最多三步，故 `&P ^4` 设置 `memory[0]=P`。再令 `memory[P]=P`。新自然数到零最多两步，随后进入 P；不足的步数由 P 自环补齐，所以统一用 `^4` 写入。表达式不得依赖 P 的旧值或破坏 0 槽。

原地更新用交换保留旧值：

```text
&0 ^1 &P ^4 &P *1 @+ ^4
```

`*1` 把旧值取到 view 并建立 P 自环，再更新并写回。自减要求旧值为正，不能把自然数槽变成负数。复制、单次条件和循环均由这些宏组合。

## 相等和大小比较

自然数 a 对应正地址 `a+1`，避开临时槽 0。判等时暂将该地址标为 -2，再读取 `memory[b+1]` 并加二做零测试，只有 a=b 才得到零。完成后恢复该地址原先的零或 -1 集合标记。-1、-2 自身始终为零。

大小比较先判相等；不相等时复制 a、b，同步递减，直到任一为零。a 副本先归零则 a<b，反之 a>b。输入不变，输出三个互斥的 0/1 标志。基本分派次数上界为 `O(min(a,b)+1)`；相等采用固定数量的分派，但宿主大整数和字典访问成本不保证恒定。

闭区间判断只组合与两个端点的比较，不逐个列出范围内的值。P003 判断 `48<=c<=57`，随后 `digit=c-48`。数字到字符同样用 `digit+48`，不含十个数字分支。

## 不枚举保留区的裸整数解码

这是此次新增的构造。仍用标准 `@input`，不改成字符输入，也不改变它的空白、加号和异常语义。

设两个原始值槽的地址为 P、Q，均为负数；其他工作槽只含自然数，未初始化动态数据区。原始值指向任一普通槽时，从原始值槽到零最多四步，所以用 `^5` 加目标自环读写。P、Q 若互指或自指，则可能破坏这个界，因而只对这两个**存储别名**设置出口，而不枚举 `0,-1,...,-B`。

入口先给 P 建立自环。输入 x=P 时沿自环直接落入 P，并在 view 中用 `x-P` 判断后直接输出 `(-P,1)`；x=Q 时用 `x-Q` 判断，直接输出 `(-Q,1)`。除此之外保存 `p=q=x,k=0`。

每轮先令 k 加一，尝试 `p-=1`；若未结束，再尝试 `q+=1`。写入候选值 y 前，用 `y-P`、`y-Q` 的零测试保护两个别名：

- p 的候选值 y 为 P 或 Q 时，`y=x-k`，故 `|x|=-y-k`，符号为负。
- q 的候选值 y 为 P 或 Q 时，`y=x+k`，故 `|x|=k-y`，符号为负。
- 未触发别名出口时正常更新；p 到零给出 `(k,0)`，q 到零给出 `(k,1)`。

别名出口必然对应负输入：正输入时 p 在到达任一负地址前已在零结束，q 则始终为正。x=0 在进入循环前结束。有限整数的某一路必然到零，或更早触发别名出口，因此解码终止，且公式精确恢复幅值。

出口先将幅值写入自然数槽，再清空 Q、P；入口自环的特殊路径与常规路径在 `memory[0]=P,memory[P]=P` 汇合后统一清理。退出时 P=Q=0，允许再次调用。`magnitude`、`sign` 不得与内部槽重叠，Q 在入口必须为零。当前调用均发生在动态结构初始化前；没有证明这个解码器能在任意动态指针图中重入。

两处入口别名测试和更新前的两个别名保护是固定结构分支，不是为每个可能输入值生成答案。步数仍与 |x| 有关；这次解决的是枚举依赖，不是高效读取天文数量级裸整数。

## 算术

非负加法复制来源为计数器，每轮目标加一、计数器减一。减法同理，前提为目标不小于来源。来源保留，参数不能占用内部计数槽。

P003 以 `m=10m+digit` 累积幅值；乘十是十次固定自增组成的常数运算。输出通过除以十寻找位权，再逐位求商余数输出字符。字面常数的固定增减和 `+`、`-`、LF 等语法判断不属于值域枚举。

P004 继续使用重复加法：完成 k 轮后 `product=k*|A|`、`counter=|B|-k`。零不输出负号，其余按符号异或输出。它原本就是通用算法，此次改用新的寻址与输入宏。分派规模为 `O(1+|A|+|B|+|A||B|)`。

非负除法要求 A>=0、B>0，以工作量 w、商 q、余数 r 和倒计数 c 维持：

```text
A = w + B*q + r
c = B-r
0 <= r < B
```

每轮 `w-=1,r+=1,c-=1`；c 为零时重置 r=0、c=B 并令 q 加一。w 到零给出商余数。P005 继续迭代 `(a,b)=(b,a mod b)`，由公约数不变和余数严格减小得正确性与终止性，`gcd(0,0)=0` 直接返回。
