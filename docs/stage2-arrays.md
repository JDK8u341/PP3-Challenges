# 阶段二：负地址数组的寻址证明

`tools/arrays.py` 生成纯 PP3 数组操作。以下 P、B、X 都是模板占位符，生成时替换为整数地址；没有增加运行时操作。

## 内存分区

普通槽共 N 个，位于 `-1..-N`。数组起点为 `-B`，其中 `B=N+1`，元素 i 位于 `-B-i`。数据区与固定变量不相交，下标不设固定上限。

阶段二每个程序只使用一段数组。`NegativeArray` 的 name 仅用于给指针和内部计数器命名，不代表另外分配一段不相交的数组；同时使用多个独立数组需要另行设计布局。

数组元素和普通槽的值均非负，只有专用指针槽 P 保存负地址 X。地址 0 是临时指针，所有正地址的内存值始终为 0。

帧长先解码再初始化数组。只有非负长度进入处理路径，因此不会把解码负数留下的危险载荷带入动态数组操作。指针槽不使用普通 `put` 或 `change`，因为它存放的 X 可能指向非零元素。

## 为什么指针需要深度 4

先执行 `&0 ^1` 清零 0 槽。若指针尚未初始化，`P→0→0→0`；若保存数组地址 X，且 `memory[X]=v>=0`，则 `P→X→v→0`。因此 `&P ^4` 总能把 P 写入地址 0。

让 `memory[P]=P` 形成自环后，从数组地址 Y 出发三次跳转：

```text
若 memory[Y] 非零：Y → v → 0 → P
若 memory[Y] 为零：Y → 0 → P → P
```

因此可以把任意当前数组地址写回指针，而无需猜测元素是不是零。

## 初始化或重置

```text
&0 ^1 &P ^4 &P ^1 &-B ^4
```

先令 `memory[0]=P`，再令 `memory[P]=P`，最后从起始数组地址按上述路径写回指针。重置时数组首元素可以已经非零。

## 移到下一元素

```text
&0 ^1 &P ^4 &P *1 @- ^4
```

`*1` 将旧地址 X 交换到 view，同时建立指针自环。自减得到 X-1，它仍属于数组区域，再由深度 4 写回指针。这不要求当前或下一元素为空。

## 读取和写入

读取：`&P ~1 ~1`，先得到数组地址，再得到非负元素。

写入非负新值 V：

```text
&0 ^1 &P ~1 ^3 &0 ^2 EXPRESSION ^3
```

`&P ~1` 得到 X；在 0 槽为零时，X 经两次跳转到 0，所以 `^3` 令 `memory[0]=X`。随后清元素，再复用阶段一的安全非负写入逻辑。V=0 时即使最后写到 0 槽，元素也已经清零。

元素自增或自减：

```text
&0 ^1 &P ~1 ^3 &P ~1 *1 @+ ^3
```

先令 0 槽指向 X，再交换取出旧元素并令该元素自环。对非负新值 V，非零时路径 `V→0→X`；零时路径 `0→X→X`。元素恢复为普通非负数据，指针槽仍保存 X。自减仅可用于正元素。

## 寻址和复杂度

`seek(i)` 先复制非负下标，再重置到首元素，逐次前移 i 次，因此运行量为 `O(i+1)`。P007 的 i 是字节码点，最多 255；P006 顺序追加和回放，每次前移是常数条基本指令。

这组宏证明的是动态数组基础，不声称已经提供常量时间的任意下标访问。正地址默认值仍可能因 `defaultdict` 读取而产生字典项，实际宿主内存不能只按显式槽数量计算。
