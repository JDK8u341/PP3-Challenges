# P004：有符号乘法证明

共同的整数解码、槽位安全性和自环更新见 [阶段一宏证明](../../docs/stage1-macros.md)。

输入被静态展开的纯 PP3 解码为 `|A|,|B|` 以及各自的负号标志；生成器不读取输入。解码前先识别保留地址附近的有限负数，其余使用双向搜索，因此任意输入整数不会因为碰巧等于变量地址而破坏内存。

乘积 p 初始为 0，计数器 c 初始为 `|B|`。每轮在复制计数器中对 `|A|` 次逐一自增 p，再令 c 减一。外层不变量是 `p=(|B|-c)|A|`。c 是非负整数且每轮减一，结束时 `c=0`，故 `p=|A||B|`。A 或 B 为零都得到零幅值。

仅在 p 非零且输入符号不同时输出字符 `-`，随后用整数 `@print` 输出非负 p 和 LF。因此最终文本恰好为标准有符号乘积，没有负零。该版本不需要把负乘积写进变量槽。

时间按基本指令次数为 `O(1+|A|+|B|+|A||B|)`，包括解码及零输入时的计数。变量槽数量固定，但 `defaultdict` 读取新的数值地址时会增加字典条目，实际内存不是常量。

自动测试包括 `[-16,16]²` 的 1089 组全枚举、固定种子样例、保留地址边界和额外幅值。全部由标准运行器执行，与测试端独立的 Python 乘法结果对照；解答中不使用 cup 或 Python 乘法。
