# P004：有符号乘法器

状态：已规划，尚未实现；阶段：1。

## 题目

两行整数 A、B；输出 A×B；只用标准基本操作。

输入输出规约：整数行输入。以上为 PP3 改编题的草案，开题前确认未决规则，不改动 PP3 本身。

## 解题计划

复用符号/幅值表示与非负加法，累计乘数次；记录 O(|A|×|B|) 基线再优化。

依赖：P001。

## 验收要点

任一数为零、四种符号组合、±1、保留地址碰撞。

运行条件：禁用直接寻址，使用固定版本 PP3 的 `std_register`；不使用 cup 或自定义宿主运算替代解题。
