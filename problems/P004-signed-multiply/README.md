# P004：有符号乘法器

状态：已完成；阶段：1。

## 题目

两行整数 A、B；输出 A×B；只用标准基本操作。

输入使用标准整数行输入，输出十进制整数和 LF。不修改 PP3 运行器。

## 解题计划

使用双向向零探测解码符号/幅值，只保护两个原始工作槽的别名，不枚举保留区。用第二个幅值作为循环计数，将第一个幅值重复加到从零开始的乘积中；仅当两个操作数符号不同时输出负号。零乘积不输出负号。

循环不变量：完成 k 轮后，乘积槽为 `k*|A|`，计数槽为 `|B|-k`。终止时得到幅值 `|A|*|B|`。包括整数解码，指令步数为 `O(1+|A|+|B|+|A|*|B|)`；大幅值即使乘数为零也不保证快速解码。

依赖：P001。

## 验收要点

测试覆盖两个零操作数位置、四种符号组合、任一幅值为 1、保留地址边界以及较大有符号数。乘法结果按十进制整数和 LF 输出。

运行条件：禁用直接寻址，使用固定版本 PP3 的 `std_register`；不使用 cup 或自定义宿主运算替代解题。
