# P007：字节排序

状态：已完成；阶段：2。

## 题目

给定长度和码点在 0..255 的序列，升序输出且保留重复次数。

输入采用[字符帧协议](../../docs/stage2-frames.md)：首行整数 n，之后消费 n 个逻辑字符，码点限制 0..255，LF 计入帧长度。输出升序字符，不额外补换行，NUL 也是有效数据。

负长度或超范围码点只输出 `ERROR\n`；字符不足保留 EOFError。结果在整帧消费和验证成功后才开始输出。

## 解题计划

每个字符保存为独立记录，记录头始终为零，载荷与后继分字段存储。读取成功后实施自底向上的稳定链表归并：段长从 1 开始翻倍，每次比较两段表头并摘取较小者，剩余段整体拼接。

算法不扫描值域或分桶，载荷相等时优先取左段，保持稳定性。排序宏接受任意自然数，字节限制仅属于题面。比较次数和节点操作均为 `O(n log(n+1))`，显式节点空间 O(n)；比较仍可能逐次递减数值，并不保证快于旧字节计数排序。原 BF 题的零结束协议改为长度协议，因而允许码点 0。

依赖：P003。

## 验收要点

全码点逆序输入、重复值、空序列、已排序、NUL、255、随机帧、非法帧；逐项检查升序和多重集。另直接测试排序宏的超字节载荷、稳定性、节点守恒和无环。

运行条件：禁用直接寻址，使用固定版本 PP3 的 `std_register`；不使用 cup 或自定义宿主运算替代解题。
