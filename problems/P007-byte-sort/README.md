# P007：字节排序

状态：已完成；阶段：2。

## 题目

给定长度和码点在 0..255 的序列，升序输出且保留重复次数。

输入采用[字符帧协议](../../docs/stage2-frames.md)：首行整数 n，之后消费 n 个逻辑字符，码点限制 0..255，LF 计入帧长度。输出升序字符，不额外补换行，NUL 也是有效数据。

负长度或超范围码点只输出 `ERROR\n`；字符不足保留 EOFError。结果在整帧消费和验证成功后才开始输出。

## 解题计划

实现 256 桶计数排序。收到合法码点 c 后，从负地址数组起点前移 c 次，到达桶 c 并自增频次。读取结束后，从桶 0 到桶 255 顺序输出相应次数的字符。

相较插入排序，固定字节域让该方案无需维护变长已排序序列。桶寻址最多前移 255 次；逻辑数据区最多 256 个频次槽，与帧长无关。原 BF 题的零结束协议改为长度协议，因而允许码点 0。

依赖：P003。

## 验收要点

全码点逆序输入、重复值、空序列、已排序、NUL、255、随机帧、非法帧；逐项检查升序结果及输入输出多重集一致性。

运行条件：禁用直接寻址，使用固定版本 PP3 的 `std_register`；不使用 cup 或自定义宿主运算替代解题。
