# P007：字节排序

状态：已规划，尚未实现；阶段：2。

## 题目

给定长度和码点在 0..255 的序列，升序输出且保留重复次数。

输入输出规约：定长字符帧（草案）。以上为 PP3 改编题的草案，开题前确认未决规则，不改动 PP3 本身。

## 解题计划

先确定数组访问模板，再比较计数排序和插入排序；从排序 1..255 的原题扩展到允许 0。

依赖：P003。

## 验收要点

空序列、已排序、逆序、重复值、0 与 255；字符帧和原始字节差异须先确认。

运行条件：禁用直接寻址，使用固定版本 PP3 的 `std_register`；不使用 cup 或自定义宿主运算替代解题。
