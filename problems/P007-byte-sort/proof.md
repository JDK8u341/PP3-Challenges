# P007：稳定链表归并排序

保留[字符帧协议](../../docs/stage2-frames.md)：输入长度及 n 个码点 0..255 的逻辑字符；有效帧升序输出且不补 LF。主解已由 256 桶改为比较排序，记录布局见[数组与记录](../../docs/stage2-arrays.md)。

## 加载与节点身份

每个有效字符分配一个新记录，幅值字段为码点、辅助字段为零，尾插到源链。即使两个字符相同，记录地址也不同；NUL 只作为载荷，空引用仍为地址零。

整帧通过校验前不排序、不输出。负长度只输出 ERROR；越界码点记错后排空帧，最后只输出 ERROR。任何提前 EOF 仍传播，且未输出部分结果。

## 自底向上归并

段长 width 初始为 1。每轮从源链依次摘出至多 width 个节点作为左段，再摘出至多 width 个节点作为右段。源链耗尽时可只有左段，或右段不足 width。

两段非空时，读取它们的表头载荷 a、b，用通用自然数比较判断大小。a>b 时摘出右头，否则摘出左头，接到输出链尾。因此相等时总选择左段。任一段空后，将另一段整体拼接到输出链，清空其控制槽。

完成一遍后将输出链所有权移回源链，width 翻倍。width>=n 时结束；空链和单节点直接跳过。

## 正确性不变量

每轮开始，源链由至多 width 个节点的有序段组成。初始单节点段显然有序。合并两个有序段时，每次取两头较小者，因此输出前缀有序；剩余段内元素均不小于已输出末项，整体拼接保持有序。于是每轮结束形成至多 2*width 个节点的有序段。

width 每轮翻倍，有限 n 在有限轮后落入一个有序段，故源链非降序。所有转移先摘再接，源节点恰好处理一次，未复制或丢弃，所以输出多重集和长度不变。

相等时左优先，且两段对应原顺序中先后相邻的区间；归纳可知相同载荷节点保持原始相对顺序。即便字节输出无法观察相同字符的身份，独立宏测试仍通过辅助字段存原始序号来验证稳定性。

## 不依赖字节值域

`merge_sort` 中没有 256、桶、按键定位或每个值的分支。它只要求载荷为自然数。字节限制属于本题输入验证；测试直接用同一排序宏处理 256、300、1001、4096，以及相等的 100 位整数，无需改变算法或重新按值域生成分支。有限样例是运行证据，任意自然数的适用性来自比较和归并的不变量。

## 成本

归并为 O(n log(n+1)) 次节点操作和至多同阶比较，显式记录空间 O(n)。通用比较先地址判等，若不等则同步递减，分派上界为 O(min(a,b)+1)。最大载荷为 M 时，总上界可写为 O((M+1)n log(n+1)+1)，另外计入帧加载与长度解码；本题 M=255。

这不保证比旧字节计数排序快。旧版利用固定小值域具有线性界；新主解的价值是通用比较和节点重连，可移到更大值域。实际分派样本见 `results/general-algorithms.json`，宿主秒数和整数成本另计。
