# P007：计数排序证明

输入输出采用[阶段二字符帧](../../docs/stage2-frames.md)，不使用原 BF 题的零结束协议。数组宏见[寻址证明](../../docs/stage2-arrays.md)。

## 频次不变量

256 个桶初始值为 0。收到码点 c 时，重置指针到桶 0，前移 c 次到达桶 c，再仅将该元素自增一。数据区地址为 `-B-c`，与固定槽不重叠；c 已验证在 0..255，所以不访问其他桶。

处理 k 个合法字符后，每个桶 v 的值恰好等于输入前 k 个字符中 v 的出现次数。整个读取过程不减少桶值，不遗漏码点 0，也不对 255 溢出取模。

## 升序输出与重复次数

完整帧通过校验后，按 0..255 顺序访问桶。每个桶复制频次到输出计数器，输出当前码点相应次数。复制计数器递减到 0，不改变桶本身。

因此输出非降序；对每个码点 v，输出次数与其输入次数完全相同。总输出长度为所有频次之和 n，多重集保持不变。空帧不输出任何字符，也不额外追加 LF。

## 错误与成本

发现超范围字符只记录错误，仍继续读取到声明长度；错误帧不访问输出过程。EOF 在任何结果输出前传播。负长度在读取负载前拒绝。

每次寻桶最多 255 次前移，故实际为 `O(n*256+256+n)` 的基本操作上界。字节域固定后简写为 `O(n+1)`。逻辑桶空间为 256 个整数槽，不能将 Python 任意精度整数或 `defaultdict` 的物理开销视为固定字节量。

测试检查全部 256 个码点、重复次数、NUL、已排序和逆序、随机输入；并以独立排序与 Counter 结果验证。
