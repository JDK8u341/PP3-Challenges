# P008：行、词和字节统计

状态：已规划，尚未实现；阶段：2。

## 题目

统计帧内 LF、由 ASCII 空白分隔的词数及输入码点数。

输入输出规约：定长字符帧（草案）。以上为 PP3 改编题的草案，开题前确认未决规则，不改动 PP3 本身。

## 解题计划

一个是否在词内的状态位，加三个计数器；字符帧只纳入 0..255。

依赖：P003。

## 验收要点

空文本、多空白、无结尾换行、连续换行；结果与独立参考实现一致。

运行条件：禁用直接寻址，使用固定版本 PP3 的 `std_register`；不使用 cup 或自定义宿主运算替代解题。
