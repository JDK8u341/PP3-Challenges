# P008：行、词和字节统计

状态：已完成；阶段：2。

## 题目

统计帧内 LF、由 ASCII 空白分隔的词数及输入码点数。

采用已确认的[字符帧协议](../../docs/stage2-frames.md)。首行长度 n，之后消费 n 个逻辑字符。码点 0..255 逐字符计为一个逻辑字节；不是 UTF-8 编码后的文件大小。

ASCII 空白严格为码点 9、10、11、12、13、32。行数为 LF 个数，词数为最大非空白连续段数，字节数为 n。输出一行 `行数 词数 字节数\n`，数字间恰好一个空格。

负长度和完整帧中的超范围字符输出 `ERROR\n`；提前 EOF 保留异常。统计结果仅在整帧成功后打印。

## 解题计划

逐字符维护行数、词数和词内状态。LF 令行数加一；通过 `9<=c<=13` 或 c=32 识别空白并清空词内状态；其他字符仅在由词外转入词内时增加词数。字节数直接使用已验证帧长。

不需要存储完整帧，错误时丢弃已经累计但尚未输出的统计值。最后复用阶段一的纯字符十进制格式化宏输出三个非负整数。

依赖：P003。

## 验收要点

空帧、六种空白、连续换行、无结尾换行、NUL、255、NBSP 非空白、全码点输入、随机帧和失败原子性；与独立状态机结果比较。

运行条件：禁用直接寻址，使用固定版本 PP3 的 `std_register`；不使用 cup 或自定义宿主运算替代解题。
