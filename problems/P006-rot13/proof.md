# P006：ROT13 正确性与延迟输出

字符协议见[阶段二字符帧](../../docs/stage2-frames.md)，数组寻址见[负地址数组证明](../../docs/stage2-arrays.md)。使用固定版本 PP3 的标准操作，禁用直接寻址。

## 范围验证

字符输入的码点非负。复制码点到探测变量，另设预算 256，同时递减两者，任一为零就停止。预算仍为正等价于原码点小于 256；原码点等于 0 时跳过循环，也有效。对于任何大 Unicode 码点，最多走 256 步即判错，不需要递减到零。

## 映射

先复制字符为默认结果。对 `c-65` 做 58 种有限分类，覆盖 65..122。

- 65..90 对应 `65 + (c-65+13) mod 26`。
- 97..122 对应 `97 + (c-97+13) mod 26`。
- 中间的 91..96 和范围外字符保持原值。

这些模运算只用于静态构造 58 个固定分支；输入 c 的分支选择由 PP3 零测试完成，生成器不读取输入。

旋转两次等价于在 26 元字母表中加 26，因此每个字母恢复原值；其他码点两次均保持不变。由逐字符应用可得任意有效帧的双重变换还原性质。

## 缓冲与错误

处理 k 个合法字符后，数组前 k 个元素恰好是已转换的前缀。指针每次后移一格，绝不依赖零作为数组终止符，因此 NUL 不会截断结果。

读完 n 个字符且无错误后，重置指针并恰好回放 n 次。此前不打印任何结果。若帧中出现超范围码点，记录错误并排空余下帧，最后只打印 ERROR；若排空中发生 EOF，异常直接传播，仍未输出任何内容。

## 成本

以 256 字节域为常量，范围检查与映射每字符成本有固定上限，顺序数组写入和回放均为常量指令数，总体按基本操作计为 `O(n+1)`，显式结果存储 `O(n)`。运行器自身的整行字符缓冲、整数表示和 `defaultdict` 条目需另外考虑。

测试覆盖全部 256 个码点、双重变换、边界标点、空帧、行尾规则、错误与随机帧；不修改上游字符输入行为。
