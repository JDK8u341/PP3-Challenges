# P006：ROT13 编解码器

状态：已完成；阶段：2。

## 题目

变换 ASCII A–Z 与 a–z；其他有效字符保持不变。

输入采用已确认的[长度行加字符帧协议](../../docs/stage2-frames.md)：首行整数 n，之后精确消费 n 个码点在 0..255 的逻辑字符，补回的 LF 计入帧。只输出转换后的 n 个字符，不额外追加换行。

负长度输出 `ERROR\n`；帧内超范围字符在整帧消费完后输出 `ERROR\n`。提前 EOF 保留异常。三种失败情况下都不会先打印任何部分转换结果。

## 解题计划

用有限零测试将码点 65..122 分类：大写与小写字母各旋转 13 位，区间中的标点以及区间外字符保持原值。转换结果先顺序存入负地址数组，整帧验证成功后才回放。

负地址数组位于固定变量之后，下标 i 的数据地址为 `-B-i`，其中 B 根据静态槽数量计算。指针用独立的深度 4 宏更新，不使用直接寻址。

依赖：P003。

## 验收要点

完整覆盖 0..255，并验证 `ROT13(ROT13(x))=x`；另覆盖空帧、标点、换行、NUL、255、非法字符、提前 EOF、剩余缓冲及固定随机帧。

运行条件：禁用直接寻址，使用固定版本 PP3 的 `std_register`；不使用 cup 或自定义宿主运算替代解题。
