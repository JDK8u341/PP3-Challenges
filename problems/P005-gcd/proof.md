# P005：GCD 的终止性和正确性

公共的符号解码及正分母长除法见 [阶段一宏证明](../../docs/stage1-macros.md)。本题只需要这些公共宏，不依赖乘法器。

## 非负商余数

设原分子 A、分母 B 满足 `A>=0,B>0`。工作量 w 初始为 A，商 q 和余数 r 初始为零，倒计数 c 初始为 B。处理过程中：

```text
A = w + B*q + r
c = B-r
0 <= r < B
```

每次令 `w-=1,r+=1,c-=1`。c 到零时，用 `r=0,q+=1,c=B` 代替完整的一组 B，恢复不变量。w 每轮减少到零，最终 `A=B*q+r` 且 `0<=r<B`，所以商余数正确。

## 欧几里得变换

输入解码后得到非负 a、b。只在 b 非零时求余，避免把零作为长除法分母。每轮更新 `(a,b)=(b,r)`。由 `a=qb+r`，a、b 的公约数集合等于 b、r 的公约数集合，因此 gcd 不变。

新 b=r 严格小于旧 b，且始终非负，所以循环必然终止。结束时 `gcd(a,0)=a`；两个输入均为零时直接输出 0，满足题目约定。

## 验证与性能

自动测试把 `[-16,16]²` 中所有输入与 `math.gcd` 对照，并检查单零、相等、互质、异号、固定随机值和保留地址边界。测试端可以调用 math.gcd，纯 DSL 解答不能。

每次余数计算按当前分子逐次递减，不能把它视为机器整数常量时间的取余。整个欧几里得过程加上解码，基本指令数可用各轮分子之和加 `|A|+|B|` 表示；这是逐一计数的正确性基线，不适合天文数量级输入。`defaultdict` 也可能随访问过的数值地址增长。
