# P005：最大公约数

状态：已完成；阶段：1。

## 题目

读取两行有符号整数 A、B，输出非负 `gcd(A,B)`；定义 `gcd(0,0)=0`，并取绝对值后计算。

输入使用标准整数行输入，输出为十进制整数和 LF。

## 解题计划

将输入解码为非负幅值。正分母的长除法通过递减被除数、递增余数、递减分母倒计数实现；倒计数归零时完成一轮商计数并恢复分母。然后反复应用欧几里得变换 `(a,b) <- (b,a mod b)`。

每次迭代保持 `gcd(a,b)` 不变，因为 `a = qb + r` 蕴含 `gcd(a,b)=gcd(b,r)`。b 每次变成严格小于旧 b 的非负余数，因此有限步后到达 0，a 即为答案。

依赖：P001。GCD 不需要乘法器，复用的是共同的非负长除法宏。

## 验收要点

(0,0)、单零、相等、互质、相邻数、正负输入、保留地址边界及较大幅值。

运行条件：禁用直接寻址，使用固定版本 PP3 的 `std_register`；不使用 cup 或自定义宿主运算替代解题。
