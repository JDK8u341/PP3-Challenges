# P003：十进制字符输入输出

状态：已规划，尚未实现；阶段：1。

## 题目

读取一行可选正负号和十进制数字，输出无冗余前导零的十进制文本。

输入输出规约：字符输入输出（草案）。以上为 PP3 改编题的草案，开题前确认未决规则，不改动 PP3 本身。

## 解题计划

先做 ASCII 数字分类、乘十加位、符号与负零规范化；再做整数到数字字符。

依赖：P001。

## 验收要点

0、-0、+0012、-0012、较长数字；空行和非法数字策略开题时确认。

运行条件：禁用直接寻址，使用固定版本 PP3 的 `std_register`；不使用 cup 或自定义宿主运算替代解题。
