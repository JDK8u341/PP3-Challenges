# P003：十进制字符输入输出

状态：已完成；阶段：1。

## 题目

读取一行匹配 `[+-]?[0-9]+` 的 ASCII 十进制整数，输出规范化十进制表示和换行。去除前导零；负零输出 `0`。

空行、只有符号、空白、非 ASCII 数字或任何其他非法字符均输出 `ERROR` 加换行。前后空白不接受。只读取第一行，后续行不消费。EOF 按运行器行为抛出 `EOFError`。

输入输出使用逐字符 `@input_as_char` 和 `@print_as_char`。Python 输入行不带末尾 LF 时，字符缓冲仍按运行器规则补回 LF；这个 LF 是行终止符，不计入整数文本。

## 解题计划

先单独处理可选符号；每个数字通过零测试分类为 0..9，并用非负幅值 `m = 10*m + d` 更新。遇到 LF 结束本行；错误标志一旦置位，只排空余下输入直到 LF，不再覆盖错误。

输出通过不断除以 10 生成十进制位权，从最高位到最低位计算商和余数。当前商加 48 后用 `@print_as_char` 输出。负号只在非零负数时输出，因此 `-0` 规范化为 `0`。

依赖：P001。

## 验收要点

测试覆盖零、负零、可选正号、前导零、长数字、错误输入、保留地址边界、仅处理首行及 EOF。

运行条件：禁用直接寻址，使用固定版本 PP3 的 `std_register`；不使用 cup 或自定义宿主运算替代解题。
