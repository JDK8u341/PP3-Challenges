# 已有斐波那契解答的归档说明

来源：本次对话先前完成的无零起始版本，以及上游 PP3 的 `test/fib.py` 中 `code2`。本轮不重新设计算法。

## 定义域

输入非负整数项数 n；输出前 n 项，从 1、1 开始，每项一行。n=0 时不输出。负数不是有效输入，原程序对负次数没有终止保证。

## 槽位

| 地址 | 用途 |
| --- | --- |
| -1 | 剩余项数 |
| -2 | 当前项 a |
| -3 | 下一项 b |
| -4 | 求和临时结果 |
| -5 | 内层加法倒计数 |
| -6 | 更新槽位前保存旧值 |

循环开始时 a、b 是相邻斐波那契项。先输出 a，再用重复自增计算 a+b，令 a=b、b=a+b，最后减少剩余次数。

数据均非负，变量地址均为负，数据地址默认值为零。当前项、下一项、求和结果和临时旧值始终为正；内层倒计数在每轮退出时为零，因此下次可以用原初始化路径重设。剩余项数只在最后一轮变为零，不再更新该槽。

## 验证与限制

仓库样例覆盖 0、1、2 和 10 项，独立期望输出写入 `cases.json`。每次运行使用新的 Runtime，禁用直接寻址，仅调用原四种标准操作。

内层加法按数值逐次自增，项数增大时执行时间会迅速增长；该实现优先展示语言可表达性，不是高性能大项数算法。
