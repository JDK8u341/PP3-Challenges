# P012：PP3 子集自解释器

状态：已完成约定子集；阶段：5。题面于 2026-11-07 确认，为 PP3 改编。

## 题目

用 PP3 解释以下核心子集。源码/数据使用与 P011 相同的[双长度字符帧](../../docs/interpreters.md)。ASCII 空白 9..13、32 分词，括号必须是独立 token；空源码合法。

| token | 支持范围与语义 |
| --- | --- |
| `&n` | n 匹配 `[+-]?[0-9]+`；任意有符号整数，前导零和负零合法 |
| `~d` | d 匹配 `[+]?[0-9]+` 且 d>0；从 view 出发读取第 d 层 |
| `^d` | 同上；定位第 d 层，把原 view 写入目标，保留 view |
| `*d` | 同上；定位第 d 层，交换 view 与目标 |
| `[`、`]` | 支持嵌套、空循环；view 非零时重复执行 |
| `@+`、`@-` | view 任意精度有符号自增/自减 |
| `@input_as_char` | 消费客体数据帧，下一个码点写入 view |
| `@print_as_char` | 输出 chr(view mod 256)，保留 view，不补 LF |

客体 view 初始为零；内存是双向无界整数地址映射，缺失值为零。读零会建立内存项，保持原运行器可观察的插入顺序。间接深度 0 与负深度被原版构造器拒绝，本题也拒绝。

负帧长、帧内非法码点、非法 token、不支持项或不匹配括号在执行前输出 `ERROR\n`，无部分客体输出。客体输入耗尽属于约定的执行错误：输出 `ERROR\n` 并停止，保留之前的客体输出；外层帧提前 EOF 则仍抛宿主 `EOFError`。整数头的解析异常不改动。

## 边界

明确不支持整数 `@input`/`@print`、`@debug`、直接寻址、cup、自定义操作、Unicode 空白、数字下划线等其他整数拼写。不设地址幅值、间接深度或客体步数上限；无终止程序仍不终止。整数存储不截断，但十进制解析及输出取模可能按幅值循环，极大数不保证实用速度。

这是“用 PP3 实现 PP3 核心子集解释器”的完成版。解释器外层加载协议使用 `@input` 读取长度，而客体子集不含该操作，因此完整解释器源码不能直接交给自身运行；不宣称完整 std 自托管。

## 解答

纯 DSL：[solution.pp3](solution.pp3)；静态生成器：`tools/stage5.py`；[证明](proof.md)、[样例](cases.json)。

源码经链式词法分析和括号配对转成指令链；客体的整数、地址统一使用符号与幅值，稀疏内存按已访问键记录。差分测试逐条比较输出、最终 view 与有序内存，覆盖负地址、零、自环、交换、任意层级路径及随机指令序列。依赖：P003、P010、P011。

运行条件：禁用直接寻址，使用固定版本 PP3 的 `std_register`；不使用 cup 或自定义宿主运算替代解题。
