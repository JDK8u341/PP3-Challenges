# P012：PP3 子集自解释器

状态：研究题，尚未实现；阶段：5。

## 题目

用 PP3 解释 PP3 的明确子集；完整 std/错误语义扩展为后续目标，不提前宣称完成。

输入输出规约：客体子集待确认。以上为 PP3 改编题的草案，开题前确认未决规则，不改动 PP3 本身。

## 解题计划

先做分词、整数解析和分派，再做 view/memory 与嵌套循环；分别确认宿主和客体的资源限制。

依赖：P003、P010、P011。

## 验收要点

每个受支持 token 与原生运行器做差分；支持矩阵逐条记录，不支持项必须明确拒绝。

运行条件：禁用直接寻址，使用固定版本 PP3 的 `std_register`；不使用 cup 或自定义宿主运算替代解题。
