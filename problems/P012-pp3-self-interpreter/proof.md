# PP3 核心子集的解释关系

## 表示

客体整数 x 编码为自然数幅值 |x| 与负号位 s；零始终规范化为 (0,0)。view 使用两个静态槽，指令立即数与间接深度使用指令记录字段 2/3。客体地址也编码成这一对，不直接成为宿主地址。

客体内存链的每条记录保存键幅值、键符号、值幅值、值符号和后继。查找只扫描已建立的记录，以通用自然数地址判等宏比较两个幅值和两个符号，找到唯一键；没有时在表尾追加零值记录。由此既保留隐式零内存，又保留读操作建立键及首次插入的顺序。客体负地址、宿主静态槽同名的数值以及客体 0 槽不会与解释器自身别名。

## 解析

按约定的 ASCII 空白积累 token 字符链。数值 token 解析一次可选符号，再逐个判断 48..57，按 a←10a+digit 累加幅值；不展开可能出现的数值。深度要求正数，立即数允许任意符号。固定操作名按字面匹配；不支持项和非独立括号拒绝。括号引用栈与 P011 共用，其配对正确性相同。

## 执行

立即数直接复制幅值和符号。自增/自减按符号分别增减幅值，在经过零时改变或清除符号，故与整数 x±1 一致。

对深度 d 的间接操作，先把原 view 复制到独立的地址工作对。重复 d-1 次“查找该键、读取其值为下一地址”，此时地址恰为原运行器的最终 place。再次查找后分别读、写或交换值。寻址过程不修改保存原 view 的工作对，因此 Set 写的是原 view，Swap 也同时保存旧 view 和旧目标值，而非路径中间值。

循环仅检查 view 的幅值是否为零，符号不影响真值。平坦指令链在闭括号的非零情形跳向开括号后继，等价于原版反复执行 body；零情形流向闭括号后继。读取字符把符号清零，输出用幅值除以 256 的余数 r，再对负数取 (256-r) mod 256，不改变客体 view。

由空 view/内存的初态和上述逐指令模拟，在受支持语法且客体输入足够时，程序的输出、最终 view、有序内存与原运行器一致。语法拒绝和客体 EOF 采用题面另行确认的错误协议，没有把该协议冒称为原版异常类型。

## 代价与限制

若已访问 A 个不同地址，一次查找扫描至多 A 条记录；深度 d 的操作需要 O(dA) 次记录比较。相等判断借助自然数标记路由，不递减键值域。十进制累加和字符输出取模仍采用通用一元算术，因此不是高性能客体大整数实现。内存随源码、数据与已访问地址增长，不按地址幅值预分配，也不枚举所有可能的地址。

测试直接调用原运行器作客体参考，并逐项核对输出、view 和内存插入序列。完整自托管与整数 I/O 的语义扩展保留为后续题目，不混入本题已经完成的核心子集。
