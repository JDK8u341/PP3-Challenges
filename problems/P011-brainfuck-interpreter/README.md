# P011：用 PP3 编写 Brainfuck 解释器

状态：已规划，尚未实现；阶段：4。

## 题目

实现八条 BF 指令；单元宽度、带边界、EOF 及代码/数据分帧须在开题前冻结。

输入输出规约：客体语义待确认。以上为 PP3 改编题的草案，开题前确认未决规则，不改动 PP3 本身。

## 解题计划

分代码加载与过滤、括号配对、指令解码、数据带四层；先做不含输入的客体子集，再补输入。

依赖：P003、P007、P010。

## 验收要点

嵌套/空循环、括号错误、回绕、指针边界、EOF；与独立 BF 参考解释器差分验证。

运行条件：禁用直接寻址，使用固定版本 PP3 的 `std_register`；不使用 cup 或自定义宿主运算替代解题。
