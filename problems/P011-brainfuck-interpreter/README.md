# P011：用 PP3 编写 Brainfuck 解释器

状态：已完成；阶段：4。题面于 2026-11-07 确认，为 PP3 改编。

## 题目

用 PP3 执行八条 BF 指令。先用两行 `@input` 分别读取非负源码长度 c、客体数据长度 d，再用字符缓冲连续消费 c+d 个码点 0..255 的字符；前 c 个是源码，后 d 个是数据。两段之间不插入分隔符。补回的 LF 是普通帧字符，详见[双帧协议与机器布局](../../docs/interpreters.md)。

| 项目 | 冻结语义 |
| --- | --- |
| 指令 | `><+-.,[]`，其他字符全部忽略 |
| 单元 | 0..255，增减按模 256 回绕 |
| 数据带 | 双向无限，初始全零，指针初始位于原点 |
| 输入 | 消费客体数据帧，耗尽后每次 `,` 写 0 |
| 循环 | 按当前单元判零，允许嵌套与空循环 |
| 输出 | `.` 输出当前字节字符，不额外补 LF |
| 错误 | 负长度、帧内非法码点、括号不匹配输出 `ERROR\n` |

执行前完整加载并校验两个帧和所有括号，错误时无部分客体输出。宿主整数解析错误、未完整读到帧的 EOF 保留原异常。客体没有步数上限，非终止程序仍不终止；测试端的参考步数预算不是语言限制。

## 解答

纯 DSL：[solution.pp3](solution.pp3)；静态生成器：`tools/stage4.py`；[证明](proof.md)、[样例](cases.json)。

代码是带后继与括号配对边的记录链；加载时用记录引用栈完成配对，执行时直接跳转。数据带按访问需要建立双向节点，跨越原点不需要负数坐标或枚举位置。

测试使用独立的数组指令/字典带 BF 模型，覆盖八条指令、嵌套与空循环、双向移动、回绕、注释、EOF 和固定随机程序；另执行一个逐格读入后倒序输出的 BF 程序。依赖：P003、P007、P010。

运行条件：禁用直接寻址，使用固定版本 PP3 的 `std_register`；不使用 cup 或自定义宿主运算替代解题。
