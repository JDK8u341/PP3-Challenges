# 文本到源码的往返证明

负地址数组保存输入帧的全部码点。数组游标与静态槽位不重叠，元素为自然数，零元素不作为终止标记。只有整个帧验证成功后才回到首元素输出源码，所以帧错误不会留下不完整程序。

对码点 c，纯字符十进制宏输出其无前导零表示，再与固定的 `&` 和 ` @print_as_char\n` 拼接。c 位于 0..255，生成的 `&c` 是合法立即数；其后字符打印的结果为 chr(c mod 256)=chr(c)，且不补换行。每行生成的 LF 是源码空白，不是额外的客体输出。

按帧顺序生成这 n 个独立片段，串接执行的结果恰为原帧。空帧对应空指令序列，输出也为空。此构造不需要字符字面量，因此 NUL、引号、反斜杠和源码括号没有特殊分支。

码点宽度固定为字节时，每个片段最多三位数字；输出源码长度、DSL 工作量和缓冲空间均随 n 线性增长。该结论不意味着产生的程序是最短形式。测试既验证源码字符串，也重新编译运行以验证语义。
