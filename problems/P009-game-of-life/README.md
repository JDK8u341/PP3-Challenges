# P009：Conway 生命游戏

状态：已规划，尚未实现；阶段：3。

## 题目

输入有限矩形棋盘与代数，按环面边界规则演化并输出最终棋盘。

输入输出规约：整数/矩形文本（草案）。以上为 PP3 改编题的草案，开题前确认未决规则，不改动 PP3 本身。

## 解题计划

先做双缓冲数组和邻居计数；先批处理，交互界面后置。

依赖：P007。

## 验收要点

空棋盘、静物、振荡器、跨边界邻居；小尺寸重复邻居规则先确认。

运行条件：禁用直接寻址，使用固定版本 PP3 的 `std_register`；不使用 cup 或自定义宿主运算替代解题。
