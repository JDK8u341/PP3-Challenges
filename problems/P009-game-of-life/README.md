# P009：Conway 生命游戏

状态：已完成；阶段：3。题面于 2026-11-07 确认，为 PP3 改编。

## 题目

依次用 `@input` 读取高度 h、宽度 w、代数 g，然后按行优先读取 h×w 个整数，每个整数独占一行。h、w、g 均须非负，格值只允许 0 或 1。整数拼写沿用标准 `@input` 的 `int()` 规则。

按 Conway 规则同步演化 g 代：八邻居恰为 3 时存活，为 2 时保持原状态，其余死亡。边界为环面；八个方向分别计数，即使小尺寸映射到同一格也重复计数。

输出 h 行连续的 0/1，每行末尾有 LF。h 或 w 为零时不读取格值，输出空文本；g 为零时输出原棋盘。负参数或非法格值输出 `ERROR\n`，无部分棋盘。完整棋盘中的非法格值不会中止其余格值的读取；负尺寸/代数在三个头参数读完后立即报错。宿主整数解析错误、提前 EOF 保留原异常。

## 解答

纯 DSL：[solution.pp3](solution.pp3)；静态生成器：`tools/stage3.py` 的 `game_of_life`；[证明](proof.md)、[样例](cases.json)。

先建立每格的东、西、北、南引用和全局遍历环，之后通过组合方向引用取八邻居。每格保存当前值与下一代值，整代算完再统一提交，不使用坐标取模或按尺寸展开分支。

测试覆盖静物、振荡器、跨边界图案、全部 1×1/1×2/2×1/2×2 初态、随机矩形、零尺寸、零代数和非法输入。依赖：P007。

运行条件：禁用直接寻址，使用固定版本 PP3 的 `std_register`；不使用 cup 或自定义宿主运算替代解题。
